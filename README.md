# BTHERE

Installers for **BTHERE**, class attendance by face and name, by [Bash IT](https://bashitgh.com).

Download the latest version from [Releases](../../releases/latest):

- **Windows**: `BTHERE_x.y.z_x64-setup.exe`
- **Mac (Apple silicon)**: `BTHERE_x.y.z_aarch64.dmg`
- **Mac (Intel)**: `BTHERE_x.y.z_x64.dmg`

BTHERE needs a licence code from Bash IT. Activating it needs the internet once; after that BTHERE works offline.
